# 비기능 요구
- 성능: 스크롤 연출은 transform/opacity만 사용, 메인 스레드 스크롤 핸들러 금지. 첫 화면 JS ≤ 50KB
- 접근성: 실제 `<a>`/`<button>`, 터치 타깃 ≥ 44px, 본문 대비 4.5:1 이상, 이미지 alt, 장식 SVG `aria-hidden`
- 문구 원칙 (AI 티 안 나게):
  - 영문 슬로건·배지 나열 금지, 한국어 문장으로. "혁신", "새로운 미래", "엔지니어링합니다", "완벽한" 같은 상투어 금지
  - 이모지, 그라데이션 배경, 좌측 컬러 보더 카드, 반짝이 아이콘 금지
  - 숫자는 출처 있는 사실만. "99% 정확도", "100%", "실시간 보호", "법적 증거" 표현 금지
  - 우주데브리스는 "발견해서 본인에게 알린다"까지만. 삭제 대행·법률 판단·증거 능력 약속 없음
  - 딥페이크: "가짜입니다" 같은 단정 금지, "합성 가능성"으로 표현. "본인이 등록한 얼굴만 대조"를 반드시 함께 표기. 얼굴 검색·닮은 사람 찾기로 읽힐 문구 금지. 정확도 수치 넣지 않음
