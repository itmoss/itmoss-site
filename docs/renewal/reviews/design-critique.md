- 날짜: 2026-10-14
- 대상: `npm run build` → `astro preview` 의 `/` (dist 산출물)

## 총평
다크 그래파이트 + 시그널 오렌지 한 점, 큰 한국어 제목, 각진 상자와 가는 선이라는 방향은 섹션 전체에서 대체로 지켜졌다. 390px 에서 가로 넘침이 없고, 내비 다섯 개가 한 줄에 들어간다. 주요 지적은 **디자인 규칙 이탈 2건 · 정보 중복 1건**이었고, 셋 다 이번 항목에서 고쳤다.

## 주요 지적과 반영

1. **버튼 모서리가 둥글다 (일관성)** — 히어로·우주데브리스 CTA·해픽 스토어 버튼이 12px 둥근 모서리로 보였다. 원인은 노트 페이지용 옛 `src/styles/global.css` 의 `.btn { @apply … rounded-xl }` 가 홈에도 실려서다. 토큰은 각진 모서리(`--radius-none: 0`)이고 카드·메일 버튼은 각져 있어 한 화면 안에서 어긋났다.
   → `src/pages/index.astro` 홈 `.btn` 에 `border-radius: var(--radius-none)` 을 더해 덮었다. 노트 페이지가 쓰는 global.css 는 건드리지 않았다.
2. **'우주데브리스가 하지 않는 일'이 좌측 컬러 보더 상자 (규칙 이탈)** — design.md 문구 원칙의 금지 패턴(좌측 컬러 보더 카드)이다.
   → `.uzu-limits` 를 왼쪽 오렌지 2px 선에서 **위쪽 1px ink 선 + 위 여백**으로 바꿨다. 같은 섹션의 대상 목록·단계 목록이 쓰는 가로 선 문법과 맞는다.
3. **같은 흐름에 번호가 두 번 (위계·정보 중복)** — 3단계 목록(01 등록 · 02 추적 · 03 알림) 바로 아래 흐름 그림이 다시 01–04 를 매겨, '03 본인에게만 알립니다'와 '04 본인 알림'이 같은 일을 다른 번호로 말했다.
   → `UzuFlowDiagram.astro` 에서 그림 안 번호를 빼고 제목·부제를 위로 올렸다. 순서는 화살표로, 단계 번호는 위 목록에만 남는다. 끝 상자 강조(오렌지 테두리)와 `role="img"`·`aria-label` 은 그대로.

반영 후 같은 방법으로 다시 캡처해 세 곳 모두 확인했다 (390·1280 둘 다, 가로 넘침 없음).

## 사소한 지적 (반영 안 함)
- 모바일 헤더가 두 줄(88px). 햄버거 메뉴로 줄이면 링크가 한 번 더 숨는다 — 지금이 낫다.
- 히어로 리드가 font-weight 300 + muted 색이라 390px 에서 가늘게 보인다. 대비 수치는 F25 에서 확인.
- 해픽 소개 문장의 「해픽」 꺾쇠 앞뒤 여백이 넓어 보인다 (전각 괄호 글리프 폭). 문구 쪽 판단이라 그대로 둔다.
- 5원칙 그림의 밝은 종이 톤 — 원본 그림을 다시 만들지 않는 한 그대로 둔다.
- '만드는 사람들' 이력 목록 들여쓰기.
