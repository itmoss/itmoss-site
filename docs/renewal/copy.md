## 개인정보처리방침

`/privacy/` — 이번 범위는 GA4(방문 분석)와 문의 메일만. 구독 항목은 구독 폼을 붙일 때 더한다.

| 자리 | 문구 |
| :--- | :--- |
| h1 | 개인정보처리방침 |
| 머리말 | 아이티모스(이하 "회사")는 홈페이지 itmoss.com 을 운영하면서 아래와 같이 개인정보를 처리합니다. 회사는 홈페이지에서 회원가입이나 입력 양식으로 개인정보를 받지 않습니다. |

### 1. 방문 분석 (Google Analytics)

- 회사는 방문 통계를 보기 위해 Google LLC 의 Google Analytics(GA4)를 씁니다.
- 수집 항목: 쿠키 식별자, 방문 페이지·방문 시각·체류 시간 등 이용 기록, 브라우저·기기 종류, IP 주소에서 추정한 대략적 지역.
- 목적: 어떤 페이지가 얼마나 읽히는지 파악해 홈페이지를 고치는 데만 씁니다. 개인을 식별하거나 광고에 쓰지 않습니다.
- 보유 기간: Google Analytics 데이터 보존 설정 기간(14개월) 동안 보관한 뒤 자동 삭제됩니다.
- 국외 처리: 수집된 정보는 Google 의 서버(미국 등)에서 처리될 수 있습니다.
- 거부 방법: 브라우저 설정에서 쿠키 저장을 막거나, Google 애널리틱스 차단 브라우저 부가기능(https://tools.google.com/dlpage/gaoptout)을 설치하면 수집되지 않습니다. 거부해도 홈페이지 이용에는 제한이 없습니다.
